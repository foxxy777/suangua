# suangua · 三硬币六爻排盘 ☯

纯前端三硬币六爻排盘器：京房八宫纳甲装卦（六亲 / 世应 / 动爻 / 变卦）+ 六十四卦图鉴 + 卦辞，**零依赖，双击 `web/index.html` 即用**，不上传任何数据。

## 功能

- **排盘**：摇六次硬币，每行点按三枚正反 → 自动装卦：本卦变卦、所属宫、世应、六亲纳甲干支、动爻标记、卦辞
- **卦图鉴**：文王六十四卦全览，点开任意卦看装卦表

## 硬币约定

- **正** = 字面（阴），**反** = 花面/国徽（阳）
- 记分：正 = 2 分、反 = 3 分，三枚加总 6/7/8/9 → 老阴 / 少阳 / 少阴 / 老阳
- 6（三正）与 9（三反）为动爻——「物极必反」，变卦时翻转
- 报卦顺序：从下往上（初爻 → 上爻）；一行内正反顺序无所谓，只按反的个数计数

## 引擎自测

```
node tests/engine.test.js
```

覆盖八宫表生成、纳甲、六亲、世应、动爻变卦等 103 项断言。

## 结构

- `web/index.html|style.css|app.js` — 页面与引擎（引擎在 app.js，Node 可直接 require）
- `tests/engine.test.js` — 引擎自测
